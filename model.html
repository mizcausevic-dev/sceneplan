Sceneplan model map

How a production, a script import, and a shoot day relate. This page is a map of the app. It is not the app.

What it is

A single-user workspace for scenes, shots, storyboards, and one shoot-day plan.

Who it is for

An independent filmmaker planning a short production on their own machine.

Why it is useful

Script text, shot estimates, and the call order stay in one database, with conflicts detected instead of overwritten.

Structure

Production, script version, scene, character, location, shot, storyboard image, shoot day, schedule item.

Discovery

Local only. The URL is printed at startup. There is no public listing.

Engagement

Edit scenes, reorder shots with buttons, upload a JPEG or PNG, assign a scene to one day.

Conversion

The output is a printed shot list or schedule the user takes to set. There is no checkout.

Money

None in this version. No accounts, ads, or paid APIs.

Launch

npm ci, npm test, npm run seed, npm start, then open the printed URL.

After launch

Next engineering task: test moving a shot between scenes, then inspect one over-long print card as a PDF.

Import decision

  1. Paste or upload UTF-8 text. The parser only recognizes the documented heading subset.
  2. If the chosen production already has scenes, stop and offer a new production. Do not merge.
  3. Show preamble, warnings, and each detected scene. The user can uncheck a scene. Unchecked text is kept in the preamble.
  4. Commit writes the immutable snapshot and the planning rows together, or writes nothing.
